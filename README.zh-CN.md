# AuraRecord - 网页版高清录屏工具

一个本地高清网页录屏工具，支持录制屏幕、应用窗口、浏览器标签页，并可同步混合录制系统音频与麦克风声音。

## 特性
- **高音质混音**：利用 Web Audio API 将系统声音和麦克风音频完美融合。
- **本地存储**：录制完的视频采用 IndexedDB 保存在浏览器本地，并支持下载 WebM 格式。
- **摄像头悬浮窗**：可在录屏时开启摄像头画面悬浮窗，支持拖拽。
- **实时音频电平监视器**：可视化麦克风输入电平，确保录制效果。

## 启动
### 方式 1：
在终端打开当前目录，运行：
  ```bash
  python -m http.server 8000
  ```
### 方式 2 (Windows) ：
  ```运行
  .\run.bat
  ```
 - 然后用浏览器访问：`http://localhost:8000`。
